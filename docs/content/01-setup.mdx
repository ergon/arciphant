## Prerequisites

### Java or Kotlin plugin

To use Arciphant in your Gradle build, you have to apply either the _Java_ or _Kotlin JVM_ plugin to all projects in the
project hierarchy:

```kotlin {2,6}
plugins {
  kotlin("jvm")
}

subprojects {
  plugins.apply("org.jetbrains.kotlin.jvm")
}
```

This is necessary since Arciphant uses the JVM-specific configurations _api_ and _implementation_ registered by these
plugins.

## Include Arciphant in your build

To integrate Arciphant, add the following to your `settings.gradle.kts`:

```kotlin settings.gradle.kts {2}
plugins {
  id("ch.ergon.arciphant")
}

arciphant {
  // your arciphant config
}
```

Arciphant is a Gradle _settings_ plugin. A _settings_ plugin is different to normal plugins in that it is applied in the
`settings.gradle.kts` file and _NOT_ in `build.gradle.kts`.
