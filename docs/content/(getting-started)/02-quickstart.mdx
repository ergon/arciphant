This walkthrough sets up a minimal Arciphant build from scratch: two modules that share the same
clean-architecture-like component structure. All you need is an empty directory with a Gradle wrapper (see
[Setup](/setup#compatibility) for the compatibility requirements).

<Steps>

<Step title="Apply the plugin">

Create a `settings.gradle.kts` and apply Arciphant:

```kotlin settings.gradle.kts
plugins {
    id("ch.ergon.arciphant") version "0.2.0"
}
```

</Step>

<Step title="Declare the module structure">

In the same file, declare a template and instantiate the modules from it:

```kotlin settings.gradle.kts
arciphant {
    val moduleTemplate = template()
        .createComponent(name = "domain")
        .createComponent(name = "application", apiDependencies = setOf("domain"))
        .createComponent(name = "web", dependencies = setOf("application"))

    module(name = "orders", template = moduleTemplate)
    module(name = "customers", template = moduleTemplate)
}
```

The template defines the technical structure that all modules share — three components and their dependencies —
and each `module(...)` call instantiates it as a domain module.

</Step>

<Step title="Apply a JVM plugin">

Arciphant requires the Java or Kotlin JVM plugin on all managed projects (see
[Setup](/setup#prerequisites)). Create the following `build.gradle.kts` in the root directory:

```kotlin build.gradle.kts
plugins {
    kotlin("jvm") version "2.2.0" apply false
}

subprojects {
    apply(plugin = "org.jetbrains.kotlin.jvm")

    repositories {
        mavenCentral()
    }
}
```

</Step>

<Step title="Inspect the generated project structure">

That's it — Arciphant now generates the whole Gradle multi-project structure. Verify it with:

```bash
./gradlew projects
```

```text
Root project 'arciphant-quickstart'
+--- Project ':customers'
|    +--- Project ':customers:application'
|    +--- Project ':customers:domain'
|    \--- Project ':customers:web'
\--- Project ':orders'
     +--- Project ':orders:application'
     +--- Project ':orders:domain'
     \--- Project ':orders:web'
```

:::tip[No build scripts needed for the components]
Arciphant also created the component folders on disk (see
[automatic folder creation](/additional-settings#automatic-folder-creation)), so you can directly start putting your
production code into `orders/domain/src/main/kotlin` etc. — without writing a single `build.gradle.kts` for any of the
components.
:::

</Step>

<Step title="Verify the wired dependencies">

Arciphant has also wired the dependencies between the components, exactly as declared in the template. The
`projectDependencies` task prints them:

```bash
./gradlew -q projectDependencies
```

```text
Project ':customers:application'
 |- [api] :customers:domain
Project ':customers:domain'
Project ':customers:web'
 |- [implementation] :customers:application
Project ':orders:application'
 |- [api] :orders:domain
...
```

`application` exposes `domain` to its consumers as an `api` dependency, so `web` has access to both.

</Step>

</Steps>
